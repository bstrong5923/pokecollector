Prefix Builder

Dev tool (not part of the game). Needs Chrome or Edge. Sprites are found automatically: a prefix named "Gooey" uses gooey.png, or a gooey/ folder of frames 0.png, 1.png, ... in public/images/prefixes.
Pick the pokecollector project folder to begin.
